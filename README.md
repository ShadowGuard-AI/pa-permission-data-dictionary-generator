# pa-permission-data-dictionary-generator
Generates a data dictionary of all permissions, their descriptions, and related resources from various permission systems. - Focused on Tools for analyzing and assessing file system permissions

## Install
`git clone https://github.com/ShadowGuardAI/pa-permission-data-dictionary-generator`

## Usage
`./pa-permission-data-dictionary-generator [params]`

## Parameters
- `-h`: Show help message and exit
- `--input-path`: Path to the directory or file containing permission data.
- `--output-file`: Path to the output JSON file.
- `--permission-system`: No description provided
- `--include-patterns`: Glob patterns to include specific files/directories.  Uses .gitignore syntax.
- `--exclude-patterns`: Glob patterns to exclude specific files/directories. Uses .gitignore syntax.
